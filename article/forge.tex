\textbf{What this document is.} A design for a substantially broader Lean~4
automation system that keeps \grind{} as its local saturation engine and adds
an outer layer that \emph{changes the proof obligation}: it selects induction
principles, generalises accumulators, synthesises auxiliary lemmas, constructs
witnesses, and obtains exact algebraic certificates. Every component that can
succeed must return something Lean can check.

\textbf{What this document is not.} \forge{} is \emph{not an implemented Lean
tactic}. None of the twenty-seven contributing efforts had a Lean executable
available; no Lean source was compiled by any of them; no comparison against
\grind{}, Aesop, \code{nlinarith}, LeanHammer, or any other Lean tactic was
measured. The Python prototypes are research code and are not formally
verified. A passing Python check is not a Lean-kernel proof.

\textbf{Baseline.} Lean v4.34.0, released 14 September 2026, with Mathlib
revision \texttt{1cf325a0cf67aca2b04d76b5380ff6a9e410aefa}.

\end{minipage}
