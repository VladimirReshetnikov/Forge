\section{Finite certificates for unbounded behaviour}
\label{sec:closure}

\subsection{The shape of the problem}

A large class of obligations has the form: \emph{for every input word, every
number of iterations, every reachable state, some observation is zero}. Program
equivalence, fold correctness, loop invariants and accumulator specifications
all land here. The universal quantifier ranges over an infinite set, so no
amount of testing settles it --- but the state space that matters is often
finite-dimensional, and that is what makes a finite certificate possible.

\S\ref{sec:structural} approached this by \emph{guessing}: propose an invariant
template, solve for its coefficients, check the base and step identities. That
works, and Proposition~\ref{prop:rec-complete} shows it is complete on its
fragment. But it has two defects that the same section had to admit.

The first is that the implemented certificate language requires a
\emph{conserved} quantity, $I(T(s))=I(s)$. That is strictly too narrow. Take
\[
 x'=2x+a,\qquad y'=2y+2a,\qquad (x_0,y_0)=(0,0),\qquad a\in\{0,1\},
\]
and the observation $q=2x-y$. After every input word $q$ is zero --- yet it is
not conserved: the rule is $q'=2q$, not $q'=q$. A worker that can only express
conservation cannot state this invariant at all, let alone prove it.

The second is the bilinearity trap. For a \emph{family} of invariants the step
condition is
\[
 I_i(T(\vec x))=\sum_j h_{ij}(\vec x)\,I_j(\vec x),
\]
and \S\ref{sec:structural} warns that discovering the $I_j$ and the multipliers
$h_{ij}$ together is a bilinear search which must not be described as linear
algebra, recommending only that one ``fix one side at a time''.

This section is what fixing one side at a time looks like when it is done
constructively. The idea is to stop guessing and start from the \emph{target}:
take the observation one actually cares about, close it under pullback along
the transition until the closure stabilises, and then solve for multipliers
over the resulting \emph{fixed} family --- which is an ordinary linear problem.
The closure either terminates with a certificate valid for every input, or it
produces a concrete input on which the observation is nonzero. There is no
template to choose and no ansatz degree to tune.

\subsection{Observable-space closure}
\label{sec:obs-closure}
\status{Implemented and tested in Python by several independent efforts.}

\subsubsection*{The fragment}

Let $A_a\in\Q^{D\times D}$ for each letter $a\in\Sigma$, let $s_0\in\Q^{D}$, and
let $q\in\Q^{1\times D}$. The goal is
\begin{equation}\label{eq:linear-goal}
 \forall w\in\Sigma^{*},\qquad q\,A_w\,s_0=0,
 \qquad A_{a_1\cdots a_t}=A_{a_t}\cdots A_{a_1}.
\end{equation}
\emph{All} words are permitted. A restricted input language needs either an
explicit product with a supplied finite automaton or a separate proof that the
restriction is respected; it must never be silently assumed.

Affine updates are included by homogenisation,
\[
 s'=M_as+b_a
 \quad\leadsto\quad
 \begin{bmatrix}s'\\1\end{bmatrix}
 =\begin{bmatrix}M_a&b_a\\0&1\end{bmatrix}\begin{bmatrix}s\\1\end{bmatrix},
\]
and an affine target likewise. Rational constants stay rational: no
floating-point rank test is needed, and none would be appropriate.

Equivalence of two implementations is the same problem. Form the block system
\[
 A_a=\begin{bmatrix}A^{(1)}_a&0\\0&A^{(2)}_a\end{bmatrix},\qquad
 q=\begin{bmatrix}o_1&-o_2\end{bmatrix},
\]
and a single zero-observation goal compares every output. Equal output requires
neither equal internal states, nor equal state dimensions, nor a shared
coordinate system --- which is exactly what makes this useful for proving two
differently written folds equal.

\subsubsection*{The algorithm}

Start from the target row and close it under right multiplication.

\begin{lstlisting}
queue := [(q, empty_word)]
basis := []
while queue is not empty:
    (r, w) := pop_front(queue)
    if r * initial != 0:
        replay w in the original matrices
        return Counterexample(w)
    if r lies in span(basis):
        continue
    append r to basis
    for each action a:
        push_back(queue, (r * A[a], prepend(a, w)))
return the closure coefficients for the completed basis
\end{lstlisting}

Dependent rows need not be expanded: multiplying their known linear combination
by $A_a$ produces the corresponding combination of rows already scheduled. Each
queued row carries a concrete word, and because a row representing $qA_w$
becomes $qA_wA_a$ under right multiplication, that word grows on the \emph{left}
--- the successor of $w$ is $aw$, not $wa$. Getting this backwards yields a
``counterexample'' that does not reproduce.

\subsubsection*{A certificate that needs no rank computation}

The search returns a matrix $G\in\Q^{r\times D}$, a row $t\in\Q^{1\times r}$,
and matrices $C_a\in\Q^{r\times r}$ with
\begin{align}
 q&=tG, \label{eq:lin-target}\\
 GA_a&=C_aG \qquad (a\in\Sigma), \label{eq:lin-closure}\\
 Gs_0&=0. \label{eq:lin-init}
\end{align}

\begin{theorem}[Observable certificate soundness]
\label{thm:linear-sound}
If \eqref{eq:lin-target}--\eqref{eq:lin-init} hold then \eqref{eq:linear-goal}
holds.
\end{theorem}
\begin{proof}
The invariant is $Gs=0$. If it holds before action $a$ then
$G(A_as)=(GA_a)s=(C_aG)s=C_a(Gs)=0$. It holds initially by
\eqref{eq:lin-init}, hence after every finite word by induction. Finally
$qs=tGs=0$ by \eqref{eq:lin-target}.
\end{proof}

The checker verifies three finite matrix identities and nothing else. It does
\emph{not} check that the rows of $G$ are independent, that they came from any
particular search, or that $r$ is minimal. Those properties explain the
algorithm's efficiency; they are irrelevant to soundness, and a certificate
carrying redundant rows is still valid. This is the cleanest search/check
separation anywhere in this document: the producer may be clever, the checker
does linear algebra.

Conversely \eqref{eq:lin-target} is indispensable. An invariant basis without
the target-membership equation may prove something perfectly true and entirely
irrelevant.

\subsubsection*{Termination, completeness, and a sharp witness bound}

\begin{theorem}[Finite-dimensional coverage]
\label{thm:linear-complete}
Without operational cutoffs, observable closure terminates and \emph{decides}
\eqref{eq:linear-goal}. If the goal is false and $q\ne0$, a distinguishing word
of length at most $D-1$ exists.
\end{theorem}
\begin{proof}
At most $D$ independent rows can be admitted, and each admitted row creates
$|\Sigma|$ successors, so the queue holds at most $1+|\Sigma|D$ entries over the
whole run. On normal termination every basis row is closed under right
multiplication by every action, so induction places every $qA_w$ in the final
row space; if all basis rows annihilate $s_0$ then so does every observation,
and otherwise a tested row supplies a concrete word.

For the bound, let $V_i$ be the span of the target rows arising from words of
length at most $i$. If $V_i=V_{i+1}$ the space is closed under each action and
the chain has stabilised. Starting from the one-dimensional span of a nonzero
$q$, at most $D-1$ strict increases are possible, so $V_{D-1}$ contains every
target row; if its evaluation at $s_0$ is not identically zero, one of its
generating words of length at most $D-1$ has nonzero evaluation.
\end{proof}

The bound is attained, and the family that attains it is the best possible
argument against testing. Take a shift matrix with ones just above the
diagonal, initial state $e_D$, and target $e_1^{\mathsf T}$: every output before
step $D-1$ is zero, and the next one is one. \emph{Testing only the first
several inputs would classify these systems as correct.} What tells us when a
conclusion is justified is the finite-dimensional argument, not the number of
samples --- which is the same lesson as \S\ref{sec:structural}'s interpolation
trap, in a setting where the trap is invisible to any finite test.

With a maintained echelon basis, row multiplication and membership reduction
cost $O(D^2)$ field operations per candidate, so an $O(|\Sigma|D^3)$
implementation exists. Bit complexity additionally depends on exact coefficient
growth, and the prototypes recompute ranks symbolically rather than maintaining
the incremental representation, so the cubic figure is a production target and
not a measured property of the delivered code.

\subsubsection*{Beyond a finite alphabet, carefully}

Suppose an update depends polynomially on a fresh scalar input,
$A(u)=\sum_{j=0}^{d}u^jM_j$. A sufficient universal certificate is
\[
 GM_j=C_jG \qquad (0\le j\le d),
\]
since then $GA(u)=\bigl(\sum_j u^jC_j\bigr)G$ for every $u$. Over an infinite
field, an output polynomial vanishing for all inputs forces all its
coefficients to vanish, so coefficient closure is complete for this precise
polynomial-input, linear-state fragment.

\begin{remark}[A coefficient matrix is not an input symbol]
If a coefficient row fails to annihilate the initial state, its index sequence
is evidence of a nonzero output \emph{polynomial} --- not a counterexample.
To produce an actual counterexample, instantiate that polynomial on an exact
grid whose coordinate sizes exceed the respective degrees, then replay the
chosen rational inputs. Presenting the coefficient indices to a user as though
they were inputs would be a semantic bug of exactly the kind
Invariant~\ref{inv:tuple} exists to prevent.
\end{remark}

\subsection{Why a span is not enough}
\label{sec:span-insufficient}

Before generalising, it is worth seeing that the generalisation is
\emph{forced}. The obstruction is not a budget that could be raised.

Compare a slow computation $z'=z^2+u$ with a fast one $x'=y+u$, $y'=(y+u)^2$,
both started from $z=x=t$, $y=t^2$, and ask whether $z-x$ stays zero. One step
gives $z'-x'=z^2-y$, so the original equation does not reproduce itself. The
missing fact is the meaning of the second accumulator, and with
$g_1=x^2-y$ and $g_2=z-x$ the pair \emph{is} stable:
\[
 g_1(F(z,x,y,u))=0,\qquad
 g_2(F(z,x,y,u))=g_1+(z+x)\,g_2 .
\]

The conceptual shift is this: do not require an equation to retain its value
after a step. Require only that the \emph{common zero set of a finite family}
be preserved. The equations may transform into polynomial combinations of one
another --- which is exactly the shape \S\ref{sec:structural} wrote down and
could not construct.

Now take the same system with $u=0$ and $p=z-x$. For $k\ge1$,
\[
 p\circ T_0^{k}=z^{2^{k}}-y^{2^{k-1}} .
\]
These have pairwise distinct highest powers of $z$, so they are linearly
independent over $\Q$: in any finite combination the coefficient of the largest
such power forces its multiplier to vanish, and descending induction kills the
rest. The vector space generated by repeated pullbacks of $p$ is therefore
\emph{infinite-dimensional}.

\begin{remark}[A routing criterion, not a fuel request]
No finite linear-span budget can close that system, at any size. The ideal lane
closes it with a single generator and the multiplier $x+y$ --- or, in the
squaring example $F(x,y)=(x^2,y^2)$ with $g=x-y$, where the pullbacks are
$x^{2^j}-y^{2^j}$, with the multiplier $x+y$ again. The two lanes do not differ
by a constant factor of effort; they use different notions of what makes an
obligation redundant. A scheduler should route on observed degree growth, not
retry the span lane with more fuel.
\end{remark}

\subsection{Target-generated ideal closure}
\label{sec:ideal-closure}
\status{Implemented and tested in Python by several independent efforts.}

Replace the row space by an \emph{ideal}: pull the target and its auxiliary
generators back through the updates and close the ideal they generate.

Fresh inputs are handled coefficientwise, and the justification is an exact
statement rather than a sampling argument.

\begin{lemma}[Extension by fresh variables]
\label{lem:fresh}
For an ideal $J\subseteq\Q[\bm x]$ and
$q(\bm x,\bm u)=\sum_\alpha q_\alpha(\bm x)\bm u^\alpha$,
\[
 q\in J\,\Q[\bm x,\bm u]
 \quad\Longleftrightarrow\quad
 q_\alpha\in J\ \text{ for every }\alpha .
\]
\end{lemma}
\begin{proof}
If every coefficient lies in $J$, expand each as a finite sum of generator
multiples and collect input monomials. Conversely, given
$q=\sum_i a_i(\bm x,\bm u)g_i(\bm x)$ with $g_i\in J$, comparing each input
coefficient expresses $q_\alpha$ as a sum of polynomial multiples of the $g_i$.
\end{proof}

No finite set of tested input values is involved: this is symbolic coefficient
extraction over independent indeterminates. It is also why processing a finite
generating set suffices --- if each current generator has a valid image then so
does every combination $q=\sum_i a_ig_i$, since
$q(F)=\sum_i a_i(F)\,g_i(F)$.

\subsubsection*{The certificate}

Per location, a finite list $G_\ell$ of polynomials, together with three
identity families: for every initial branch $b$,
\begin{align}
 g_{\ell_b,j}(I_b(\bm t))&=0 \quad\text{in }\Q[\bm t], \label{eq:base}\\
 p_a(\bm x)&=\textstyle\sum_j a_{a,j}(\bm x)\,g_{\ell_a,j}(\bm x),
   \label{eq:target}\\
 g_{m,i}(F_e(\bm x,\bm u))
   &=\textstyle\sum_j h_{e,i,j}(\bm x,\bm u)\,g_{\ell,j}(\bm x). \label{eq:step}
\end{align}

\begin{theorem}[Certificate soundness]
\label{thm:ideal-sound}
If \eqref{eq:base}, \eqref{eq:target} and \eqref{eq:step} hold, every legal
finite execution satisfies all its target observations.
\end{theorem}
\begin{proof}
Initialisation follows by evaluating \eqref{eq:base} at the chosen parameters.
If every generator vanishes at the current state, then every summand on the
right of \eqref{eq:step} has a zero factor, so every destination generator
vanishes after the edge. Induction on execution length carries the invariant to
every reached location, and at an observation point \eqref{eq:target} evaluates
to a sum of zero terms.
\end{proof}

No multiplier carries a sign condition: these are equality proofs, not
positivity certificates, and the acceptance language is exactly polynomial
addition, multiplication, substitution and rational equality.

\begin{remark}[The step matrix has an orientation]
$h_{e,i,j}$ has destination generators as rows and source generators as
columns. Swapping those dimensions is a semantic error, not a storage
convention.
\end{remark}

\subsubsection*{What the checker is spared}

The checker need not verify that a basis is reduced, minimal, a Gr\"obner
basis, or even a basis of the ideal generated by the requested targets. It
checks the three identity families against the \emph{original} problem, and an
arbitrary family of equations is acceptable when it passes.

This removes a large proof burden. The search may use Gr\"obner bases freely,
but accepting the resulting inductive relation does not require formalising the
Buchberger algorithm --- whereas a tool whose conclusion \emph{asserts} that a
set is a Gr\"obner basis would have to establish that additional fact.

\begin{remark}[Why not pass to the radical]
Only zero sets matter, so replacing $J$ by $\sqrt J$ is tempting and can shrink
the generating set. It also creates a new obligation: a radical-membership
claim $q^m\in J$ yields $q=0$ only in a setting with suitable reducedness or
integral-domain properties. The direct multiplier certificate makes no such
inference, and this is a precise instance of a search optimisation that would
silently strengthen the checker's logic.
\end{remark}

\subsubsection*{Termination}

\begin{theorem}[Unbounded target-ideal closure]
\label{thm:ideal-terminates}
For the fragment above, exact ideal closure without resource bounds terminates.
If the property holds it returns a certificate; if it fails, it exposes a
nonzero initial identity from which a finite rational counterexample is
reconstructed.
\end{theorem}
\begin{proof}
Every insertion strictly increases the ideal at one location. A polynomial ring
in finitely many variables over a field is Noetherian, so it admits no infinite
strictly ascending chain; with finitely many locations, infinitely many
insertions would force such a chain somewhere. Hence only finitely many
insertions occur, each generating finitely many worklist items, and exact
membership terminates on each finite input.

If no initial identity fails, every generator vanishes under its initial
parametrisations, and at exhaustion every generator pullback lies in the source
ideal extended by fresh input variables (Lemma~\ref{lem:fresh}); the identities
of Theorem~\ref{thm:ideal-sound} are then available. If the property is false
that conclusion is impossible, so some initial identity fails first, and its
retained provenance yields the execution.
\end{proof}

\begin{remark}[What was decided, and what was not]
This is a decision result for equality observations on the stated closed,
unguarded polynomial system. It is \emph{not} a decision result for arbitrary
program verification, real inequalities, unrestricted guards, termination,
general Lean goals, or inhabitation of a dependent type. Noetherianity is a
termination argument and not a degree or runtime bound: a single basis
computation can dominate everything, so a production deployment runs the
producer under an external deadline and reports a timeout as \unknown{}.
\end{remark}

This is the constructive answer to the bilinearity trap. The algorithm never
solves simultaneously for unknown generators and unknown multipliers: the
family is \emph{constructed} by closure, and only then are multipliers solved
for over that fixed family, which is linear. Replacing a bilinear template
search does not make the computation cheap --- it makes it well defined.

\subsection{The other direction: descending closure}
\label{sec:descending}
\status{Implemented and tested in Python by one effort.}

One contributing effort computes the closure from the opposite end, and the
contrast is instructive enough to keep.

Fix a finite-dimensional feature space $E=\Span_\Q\{m_1,\ldots,m_N\}$ ---
in practice all monomials up to some degree --- and descend:
\begin{align}
 V_0&=\{p\in E: p\circ I=0\ \text{as a polynomial}\},\label{eq:v0}\\
 V_{j+1}&=V_j\cap\bigcap_b (T_b^{*})^{-1}(V_j).\label{eq:vnext}
\end{align}
The inverse image means $p\circ T_b$ lies in the current subspace \emph{as a
polynomial}, not after discarding high-degree monomials. Since pullback
$T^{*}_bp=p\circ T_b$ is linear in $p$ even when $T_b$ is not, each step is a
linear constraint over a fixed basis.

\begin{theorem}[Termination and maximality]
\label{thm:descending}
The sequence \eqref{eq:vnext} stabilises after at most $N$ strict dimension
drops. Its limit $V_*$ is the largest subspace of $E$ vanishing under
initialisation and stable under every pullback, and every polynomial in $V_*$
vanishes at every reachable state.
\end{theorem}
\begin{proof}
Each $V_j$ is a subspace and $V_{j+1}\subseteq V_j$; a strict inclusion of
finite-dimensional spaces strictly drops dimension, so at most $N$ occur, and
equal dimensions imply a fixed point. For maximality, let $W\subseteq E$ vanish
under initialisation with $T_b^{*}W\subseteq W$; then $W\subseteq V_0$, and if
$W\subseteq V_j$ then every $p\in W$ has $T_b^{*}p\in W\subseteq V_j$, so
$p\in V_{j+1}$. Finally, every $p\in V_*$ vanishes initially, and at a
transition from a state where all of $V_*$ vanishes each $p\circ T_b$ is a
combination of members of $V_*$ and so vanishes too.
\end{proof}

The motivating gap is the same one \S\ref{sec:closure} opened with, in a
different guise: under $T(x,y,z)=(2x,3y,6z)$ the relation $p=z-xy$ satisfies
$p\circ T=6p$, so a conservation-only search discards it for a reason unrelated
to its validity. And under $T(x,y)=(y,2x)$ a family can be preserved while no
member of a chosen basis is preserved individually.

Two differences from the ascending lane are worth stating plainly, because they
determine when each is appropriate. The descending lane is \emph{not}
goal-generated: it computes the greatest stable subspace of a \emph{preselected}
feature space and only then checks that the target lies in its span, so the
answer depends on a degree choice made in advance. And it has \emph{no
counterexample mechanism at all} --- failure is \unknown{} and nothing more.
The ascending lane starts from the target, needs no feature space, and carries
the provenance that makes a negative answer concrete.

\subsection{A decision result, and its exact boundary}

The linear and ideal lanes each terminate, but only one of them decides, and it
is worth stating the decision precisely because the fragment is narrow.

Generalise the setting to a finite set of control nodes $Q$, $r$ rational
registers, and edges carrying a fresh payload $u$ and a simultaneous polynomial
update $F_e(x,u)$. The update is \emph{state-affine} if
$F_e(x,u)=A_e(u)x+b_e(u)$ --- affine in the state, with entries that may be
arbitrary polynomials in the payload.

\begin{theorem}[Exact decision in the state-affine fragment]
\label{thm:decide}
Assume all updates are state-affine and every demanded output has state degree
at most $D$. In exact arithmetic without resource truncation, observable
closure stabilises after at most
\[
 B=|Q|\binom{r+D}{D}
\]
independent generator insertions, and returns either a positive certificate or
a concrete execution counterexample.
\end{theorem}
\begin{proof}
Substituting state-affine expressions into a degree-$D$ observation does not
raise its degree in $x$, and extracting coefficients in $u$ cannot either. All
spaces therefore stay inside the degree-$D$ polynomials, whose monomial basis
has $\binom{r+D}{D}$ elements. Each insertion strictly increases the dimension
at one node, so at most $|Q|\binom{r+D}{D}$ occur, each generating finitely many
coefficient obligations; the worklist empties unless an initial generator is
found nonzero. In that case provenance reconstruction gives a counterexample.
Otherwise all initial generators vanish and exact linear dependence supplies the
certificate matrices.
\end{proof}

The same count bounds the counterexample: a nonzero retained initial generator
has an ancestry chain ending at an original goal, each edge moving to a strictly
earlier generator, so the trace has at most $B-1$ edges. That bounds the word
\emph{length}, not the bit size of its rational states.

\begin{remark}[Where it stops deciding]
Drop state-affineness and the guarantee goes with it. For $x'=x^2$ with $x_0=0$
and goal $x=0$, closure generates $x,x^2,x^4,x^8,\ldots$ and a degree cap
correctly returns \unknown{} --- on a \emph{true} property. The ideal lane
handles it immediately, since $x^2=x\cdot x$. This is the same routing
criterion as \S\ref{sec:span-insufficient} and not a defect in either lane.
\end{remark}

\subsection{Sampling cannot substitute, and the grid is not sampling}

The closure workers refute by producing a concrete input, and it is worth being
clear that this is not testing in disguise.

Take $x'=x+\prod_{i=0}^{6}(u-i)$ with $x_0=0$ and the demand $x=0$. Every
one-step sample at $u=0,1,\ldots,6$ passes. The property is nevertheless false:
coefficient extraction sees a nonzero constant observation at the initial state
immediately, and the witness construction chooses $u=7$, giving $x=5040$.

The distinction matters. The nonzero polynomial has \emph{already} been
established, exactly, by coefficient comparison. A grid is then used only to
exhibit a point where a known-nonzero polynomial does not vanish:

\begin{lemma}[A finite separating grid]
\label{lem:grid}
Let $f\in\Q[u_1,\ldots,u_m]$ be nonzero with degree $d_i$ in $u_i$. Then $f$ is
nonzero at some point of $\prod_i\{0,1,\ldots,d_i\}$. For $m=0$ the grid is the
empty tuple.
\end{lemma}
\begin{proof}
In one variable a nonzero degree-$d$ polynomial has at most $d$ roots. In
several, write $f$ as a polynomial in its last variable; if it vanished on the
whole grid then at every choice of the earlier coordinates all its coefficients
would vanish, and induction would make every coefficient polynomial zero.
\end{proof}

So the grid appears in the \emph{counterexample constructor}, never in the
verification. Finite-sample verification remains exactly as unsound as
\S\ref{sec:structural} said it was.

\begin{remark}[Two small implementation traps]
Updates are \emph{simultaneous}. Under $(a,b)\mapsto(b,a)$ from $(1,2)$ the sum
$a+b=3$ is preserved; a sequential substitution that overwrites $a$ first yields
$(2,2)$ and a different transition system. And control identity is part of the
invariant: a machine alternating
$(s,t)\mapsto(s+u,\,u-t)$ and $(s,t)\mapsto(s-u,\,u-t)$ satisfies $s+t=0$ at
even nodes and $s-t=0$ at odd ones, and a single unqualified claim would be
false on half the states.
\end{remark}

\subsection{Multipliers without trusting a basis computation}
\label{sec:tracked-buchberger}

The ideal lane needs polynomial multipliers, and the obvious way to get them is
to reduce and report that the remainder was zero. That is useful for search and
useless as a certificate: it says a computation happened, not how the result is
built from the original generators.

The fix is to track the representation through the computation. Give each
current basis element a vector $u_i$ over the \emph{original} generators with
$b_i=\sum_j u_{ij}f_j$. An S-polynomial $ab_i-cb_j$ carries $au_i-cu_j$;
subtracting $q\,b_\ell$ during reduction subtracts $q\,u_\ell$; normalising a
remainder normalises its vector by the same scalar. After reducing a requested
$f$ to zero as $f=\sum_i q_ib_i$, substitute to obtain
\[
 f=\sum_j\Bigl(\sum_i q_i u_{ij}\Bigr)f_j ,
\]
and serialise only that outer vector.

The replayer then expands one polynomial identity with its own sparse
arithmetic. It does not rerun the basis computation, and it does not need the
claimed basis to be Gr\"obner, reduced, minimal, or even linearly independent.
That is the whole point: \emph{avoid making a proof of Gr\"obner-basis
correctness an early dependency, because the final certificate never requires
that fact}.

A production backend can be substituted freely, with one obligation: a solver's
matrix convention is not part of the mathematics, so the adapter must prove its
decoded multipliers satisfy exactly \eqref{eq:step}, by multiplying them out.

\subsection{Weighted observations, tensors, and what an observable means}
\label{sec:weighted}
\status{Implemented and tested in Python by several independent efforts.}

The linear machinery extends to weighted representations
$(\alpha,\{M_a\},\beta)$ with the same three-identity certificate
\[
 \alpha=c_0B,\qquad BM_a=C_aB,\qquad B\beta=0,
\]
and the same indifference to independence: redundant rows are fine, and even a
larger non-reachable closed space certifies the result.

What this buys beyond the affine case is \emph{composition}. Pointwise products
of observations are obtained by tensoring:
$\alpha_{fg}=\alpha_f\otimes\alpha_g$,
$M^{fg}_a=M^f_a\otimes M^g_a$,
$\beta_{fg}=\beta_f\otimes\beta_g$.
So a nonlinear \emph{output} identity can be decided while the state dynamics
stay linear. Repeated tensoring multiplies dimensions quickly and needs an
explicit budget.

A worked instance shows the shape. Let $\mathrm{cnt}_{AB}(w)$ count occurrences
of $A$ before $B$ as a subsequence, and likewise $\mathrm{cnt}_{BA}$. Then for
every $w\in\{a,b\}^{*}$,
\[
 \mathrm{cnt}_{AB}(w)+\mathrm{cnt}_{BA}(w)
 =\mathrm{cnt}_{A}(w)\cdot\mathrm{cnt}_{B}(w).
\]
With a five-coordinate left state and the tensor of two affine counters on the
right, the ambient difference has dimension nine; the search finds five
reachable basis rows and examines eleven worklist rows. A short combinatorial
proof exists --- pair each $a$-position with each $b$-position --- and is
\emph{not} supplied to the search.

\begin{remark}[Name the observable]
A proved match discharges \emph{that observable contract} and nothing more.
Two list-valued functions can agree in length on every input and return
different elements in a different order. The adapter's result type should name
what it established, and never silently replace equality of functions by
equality of their counts.
\end{remark}

\subsection{Summation certificates with moving support}
\label{sec:summation}
\status{Implemented and tested in Python by four independent efforts.}

A related family of unbounded obligations is finite summation:
\[
 S_{m,W}(n)=\sum_{k=0}^{n}W(k)\binom nk^{m}.
\]
The goal is a recurrence in $n$, certified rather than asserted. The difficulty
is not convergence --- every sum is finite --- but the \emph{moving upper
endpoint}. An identity valid only for $0<k<n$ cannot be summed as though it held
at $k=0$ and $k=n+1$, and the usual rational certificate
$R(n,k)=k^mU(n,k)/D(n,k)^m$ has $D(n,k)$ vanishing exactly where shifted
summands are still nonzero.

\begin{remark}[Total division makes this worse, not better]
In Lean, field division is total. Substituting a pole and observing that the
expression evaluates to something is therefore \emph{not} a contradiction ---
the totalised value is simply not the removable extension used in the
mathematical derivation. A certificate that relies on cancelling a possibly
zero factor will look fine and prove nothing.
\end{remark}

The remedy is to change representation before specialising. With
$A(n)=\prod_{t=1}^{r-1}(n+t)$, define the \emph{regularised}
\[
 H(n,k)=U(n,k)\binom{n+r-1}{k-1}^{m},
\]
which is defined at every integer $k$ under the zero-extension convention, and
prove instead
\[
 A(n)^{m}\sum_{j=0}^{r}p_j(n)\,F_m(n+j,k)=H(n,k+1)-H(n,k).
\]
No rational pole appears in that statement.

\begin{theorem}[Pole-safe summation certificate]
\label{thm:telescope}
If the cleared polynomial identity holds, together with the lower-boundary
identity at $k=0$ and all $r$ upper-boundary identities at $k=n+t$, then
$\sum_{j=0}^{r}p_j(n)S_m(n+j)=0$ for every $n\in\N$.
\end{theorem}
\begin{proof}
The interior and boundary arguments give the regularised identity for every $k$
in $0\le k\le n+r$. Sum over that range: each shifted summand vanishes beyond
$n+j$, so its sum is exactly $S_m(n+j)$, and the right side telescopes to
$H(n,n+r+1)-H(n,0)=0$ --- the upper term because its binomial has lower index
$n+r$ against upper index $n+r-1$, the lower because its lower index is $-1$.
The left side is $A(n)^m$ times the claimed recurrence, and every factor of
$A(n)$ is positive.
\end{proof}

The boundary conditions are checked \emph{symbolically}, as univariate
polynomial identities in $n$, not by evaluating finitely many numerical $n$.
That is the part a generic computer-algebra answer usually omits, and it is
where the certificate earns its keep.

\begin{remark}[A recurrence is not a characterisation]
To identify a sequence, a recurrence needs a leading coefficient that never
vanishes on the range plus enough initial values. The mutation that makes this
concrete is elegant: multiply every $p_j$ and the numerator by $n-2$. Every
interior and boundary polynomial identity still holds, and the recurrence is
still \emph{true} --- but its leading coefficient vanishes at $n=2$ and the
uniqueness argument collapses. A checker must reach and reject that step. The
two outputs are genuinely different results and deserve different constructors:
one proves a recurrence, the other characterises a sequence.
\end{remark}

\begin{remark}[Operator normal form]
If recurrences are stored as operators $L=\sum_j p_j(n)E_n^{\,j}$, note that
$E_n\,n=(n+1)E_n$: ordinary commutative polynomial multiplication is \emph{not}
operator composition. A checker that merely evaluates the listed coefficient
polynomials at the current $n$ sidesteps the ambiguity; an operator engine must
preserve it explicitly.
\end{remark}

\subsubsection*{Sizing the ansatz, and one design flaw worth recording}

The extension round adds a geometric weight, $S_{p,q}(n)=\sum_k q^k\binom nk^p$,
and fixes the flux language to shifted summands rather than a rational
multiplier:
\[
 G(n,k)=\sum_{j=0}^{r-1}P_j(n,k)\,q^k\binom{n+j}{k-1}^{p}.
\]
Both end fluxes are then structurally zero --- $G(n,0)$ uses the signed lower
index $-1$, and in $G(n,n+r+1)$ the lower index $n+r$ exceeds every $n+j$ with
$j<r$. No limiting argument appears anywhere. The factor $q^k$ is multiplied
back and \emph{never divided out}, so the same certificate covers $q=0$ under
the ordinary convention $0^0=1$.

Searching for $a_i(n)=\sum_{a\le d_a}c_{i,a}n^a$ and
$P_j(n,k)=\sum_{a+b\le d_P}d_{j,a,b}n^ak^b$ gives a linear system in
\[
 (r+1)(d_a+1)+r\binom{d_P+2}{2}
\]
unknowns. Here is the flaw the fourth effort found in its own earlier revision
and fixed before delivery: it first computed the \emph{interior} nullspace and
then tested each basis vector against the boundary identities. That is not
complete, because a useful solution can be a linear combination of basis vectors
none of which passes the boundary test alone. The boundary rows must enter the
matrix \emph{before} the nullspace calculation. With them included, if every
basis vector has $a_r=0$ then so does every combination, and the honest report
is \code{UNKNOWN\_FIXED\_ANSATZ} --- not ``no recurrence exists'' and certainly
not ``the identity is false''. Completeness here is completeness for one finite
linear system at one prescribed order and degree bound. It says nothing about
the union of this flux language over all bounds, still less about creative
telescoping in general.

The recovered certificates are small enough to print. For the binomial theorem,
$a_0=-(1+q)$, $a_1=1$, $P_0=-1$. For squared binomials at $q=1$,
$a_0=-2(2n+1)$, $a_1=n+1$, $P_0=2k-3n-3$, giving $(n+1)S(n+1)=2(2n+1)S(n)$,
which with $\binom{2n}{n}$'s factorial recurrence and $S(0)=1$ proves
$\sum_k\binom nk^2=\binom{2n}n$. At $n=0$ the boundary cell $k=1$ contributes
exactly the term the recurrence needs; dropping it is not harmless tidying of a
zero tail. The alternating case $q=-1$ yields $(n+2)S(n+2)+4(n+1)S(n)=0$ --- a
stride-two operator with a zero middle coefficient, which is precisely why a
worker should keep the whole operator instead of assuming every identity
reduces to a first-order ratio. Franel numbers ($p=3$) give
$(n+2)^2S(n+2)-(7n^2+21n+16)S(n+1)-8(n+1)^2S(n)=0$ from a $54\times21$ system
with nine boundary rows and a one-dimensional nullspace; the fourth-power case
needs $r=d_a=d_P=3$, a $159\times46$ system, and lands in a two-dimensional
nullspace. That last is an acceptance of \emph{a} correct recurrence, not a
claim that order three is minimal: requiring minimality in the checker would add
cost without strengthening the theorem a valid annihilator already gives.

A parametric order-two certificate is checkable for every rational $q$ ---
$a_0=(q-1)^2(n+1)$, $a_1=-(q+1)(2n+3)$, $a_2=n+2$, $P_0=(q-1)(n+1)$,
$P_1=2k-3n-6$ --- but the executed search fixed $q$ before solving, and the
symbolic expansion that confirms it for all $q$ was a separate script outside
the certificate corpus. The distinction is recorded rather than elided.

\begin{remark}[The lower index must be signed]
This is the translation trap that would silently destroy the whole argument.
In Lean, \code{Nat} subtraction truncates: $0-1=0$. Rendering
$\binom{n}{k-1}$ with a natural lower index therefore makes the supposedly zero
\emph{left} flux nonzero, and the telescoping theorem becomes false in the
formalisation while remaining true on paper. The interface needs an explicitly
signed lower index --- a \code{chooseZ : Nat -> Int -> Rat}, zero for negative
indices, with proved agreement with \code{Nat.choose} on nonnegative ones. The
supporting library then needs: vanishing outside the support, the interior
shift-ratio identities \emph{with} their inequalities, complement symmetry at
the top boundary, the fixed-lower-index product formula, finite-sum
interchange, and the telescoping endpoint theorem. A \code{field\_simp} call is
not a substitute for the missing domain proofs. In a \code{Finset.range}
encoding, the sum uses $n+1$ while the common support used in the proof has
length $n+r+1$; an off-by-one in either range changes the theorem.
\end{remark}

\subsection{Transporting between annihilating operators}
\label{sec:ore}
\status{Implemented and tested in Python \src{e9}; no Lean discharge.}

Two sequences with recurrences are rarely given by the \emph{same} recurrence.
To compare them, find one operator that annihilates both. A certificate of a
common \emph{left} multiple is three operators with
\begin{equation}\label{eq:left-multiple}
 L=UA=VB,
\end{equation}
where the problem supplies $A$ and $B$ and the certificate may not redefine
them. The checker expands both products using the Ore rule
\begin{equation}\label{eq:ore}
 \bigl(a_i(n)E^i\bigr)\bigl(b_j(n)E^j\bigr)=a_i(n)b_j(n+i)E^{i+j},
\end{equation}
requires all three operators canonical with nonzero final coefficient, and
claims nothing about minimality.

\begin{proposition}[Annihilator transport]\label{prop:transport}
If $Af=0$ and $Bg=0$ on $\N$, and \eqref{eq:left-multiple} holds with polynomial
coefficients and nonnegative shifts, then $Lf=Lg=0$ on $\N$.
\end{proposition}
\begin{proof}
For all $n$, $(UA)f(n)=U(Af)(n)=0$, since every shifted index stays natural; the
same calculation applies to $V(Bg)$. Identity~\eqref{eq:ore} is exactly what
makes composition of actions agree with operator multiplication.
\end{proof}

For $A=E-(n+1)$ and $B=E-2(n+1)$ the search returns $U=E-2(n+2)$,
$V=E-(n+2)$ and
\[
 L=E^2-3(n+2)E+2(n+1)(n+2).
\]
Treating $E$ as a commuting indeterminate produces the wrong middle
coefficient, and a dedicated test rejects commutative multiplication as a
substitute. The example is an operator-composition test; it is emphatically not
a claim that the factorial and doubled-factorial solutions of those two
first-order operators are equal. That still needs the initial-value proofs.

\subsubsection*{A nonvanishing leading coefficient is a hypothesis, not a formality}

Given $\sum_{i=0}^r p_i(n)f(n+i)=0$ with $p_r\not\equiv0$ and $r\ge1$, the usual
argument --- match $r$ initial values, then induct --- fails at a natural root
of $p_r$. Knowing that $p_r$ is a nonzero \emph{polynomial} is not enough: a
polynomial can be nonzero as an expression and zero at a specific natural index.
The countermodel is elementary and worth stating, because it is the kind of
thing a plausible-looking tactic gets wrong. For
\[
 (n-5)\bigl(f(n+1)-2f(n)\bigr)=0,
\]
both the zero sequence and
\[
 g(n)=\begin{cases}0,&n<6,\\2^{\,n-6},&n\ge6\end{cases}
\]
are solutions. They agree at indices $0$ through $5$ and differ at $6$. Six
matching initial values do not settle a \emph{first-order} recurrence.

\begin{theorem}[Singularity-aware equality]\label{thm:seeds}
Let $\Sigma=\{s\in\N:p_r(s)=0\}$, which is finite, and let
$I=\{0,\ldots,r-1\}\cup\{s+r:s\in\Sigma\}$. If $f$ and $g$ both satisfy the
recurrence and $f(i)=g(i)$ for every $i\in I$, then $f=g$ on $\N$.
\end{theorem}
\begin{proof}
Set $h=f-g$, which satisfies the same homogeneous recurrence, and induct
strongly on $m$. If $m<r$ then $h(m)=0$ by hypothesis. Otherwise write $m=n+r$.
If $p_r(n)=0$ then $m\in I$ and the hypothesis applies again. If $p_r(n)\ne0$,
the recurrence at $n$ reads
$p_r(n)h(m)=-\sum_{i<r}p_i(n)h(n+i)=0$ because $n+i<m$ for every $i<r$;
cancel in the field.
\end{proof}

The seed set is sufficient, not minimal --- another relation can sometimes
supply a value this theorem asks for separately. Its advantage over demanding
every value up to the largest singular index is that it asks only for the
initial window plus the exceptional pivots. Repeated roots cost nothing extra.
For the example above the required set is $\{0,6\}$; for a third-order
recurrence with natural leading roots $0,1,5$ it is $\{0,1,2,3,4,8\}$. A seed at
$s$ rather than $s+r$ is an off-by-order error, and it does not repair the
missing pivot.

\subsubsection*{The checker must find the roots itself}

A producer-supplied root list is exactly the kind of assertion this architecture
refuses. With $p_r(n)=a_dn^d+\cdots+a_0$ and $a_d\ne0$, the certificate supplies
an integer
\begin{equation}\label{eq:cauchy}
 B\ge1+\max_{0\le i<d}\left|a_i/a_d\right|,
\end{equation}
the claimed natural roots, and the proposed seed set. The checker verifies
\eqref{eq:cauchy}, evaluates $p_r$ exactly at every integer in $[0,B]$, compares
the complete sorted root list, and recomputes $I$. Completeness of the bound is
the standard Cauchy argument: if $|z|>1+C$ with $C=\max_{i<d}|a_i/a_d|$, then a
zero would give
$|z|^d\le C\sum_{i<d}|z|^i\le \frac{C}{|z|-1}|z|^d<|z|^d$.
Constant $p_r$ has no roots and uses $B=0$. There is no floating-point root
finding anywhere, and no solver assertion that all roots were found.

The enumeration is deliberately simple and sometimes wasteful; large
coefficients make $B$ enormous, and the prototype refuses bounds above
$100\,000$, returning \unknown{} from the \emph{producer}. That is a resource
policy, not a conclusion about roots. A positive-factor or Sturm cover would cut
the work --- and since Section~\ref{sec:nonlinear} already proposes Sturm
machinery, the right move is to reuse a proved version rather than declare
another root counter new.

\begin{remark}[Apparent singularities are still singularities]
Transport can manufacture them. From $A=E-(n+1)$ and $B=E-2$ the search returns
\[
 L=(n-1)E^2+(-n^2-3n+2)E+2n(n+1),
\qquad
 U=(n-1)E-2n,\quad V=(n-1)E-n(n+1).
\]
Both original operators are monic, yet this common multiple has a natural
singularity at $1$, so the safe plan carries an extra seed at $1+2=3$. One may
look for a different multiple, or exploit the originals, to avoid that work. One
may not discard the factor or omit the seed on the grounds that the singularity
``came from the algorithm''. This also gives the scheduler a real cost signal:
compare candidate multiples by checked operator size, estimated verification
cost, and the number and difficulty of their residual seed goals.
\end{remark}

The proof plan therefore has five arrows and no shortcuts:
\[
\begin{gathered}
 \text{source correspondence}\;\longrightarrow\;
 \text{two proved annihilations}\\
 \longrightarrow\;\text{checked common operator}\;\longrightarrow\;
 \text{complete singularity cover}\\
 \longrightarrow\;\text{proved seed equalities}\;\longrightarrow\;
 \forall n,\ f(n)=g(n).
\end{gathered}
\]
Each arrow is an independent obligation, and no stage may stand in for one after
it. The forty-seven recorded singularity objects verify complete seed
\emph{plans} for their encoded operators; they contain no proof that two
particular sequences satisfy those recurrences, and no proof of the seed
equalities themselves. Where both sides already share a first-order operator ---
the squared-binomial case, for instance --- the common-multiple search should be
skipped entirely.

\subsection{Finite-algebra covers for inductive data}
\label{sec:covers}
\status{Implemented and tested in Python \src{e8}; no Lean discharge.}

The closure workers above summarise \emph{sequences} of actions. A different
unbounded family is summarised by a finite abstraction of a \emph{tree}. Let a
datatype have constructors $c$ of arity $a(c)$, let $Q$ be a finite state set
with transitions $\delta_c:Q^{a(c)}\to Q$, and let $G\subseteq Q$ be the good
states. The goal is that every finite constructor tree summarises into $G$.

\begin{definition}[Inductive cover]
$R\subseteq Q$ is an inductive cover if
$\delta_c(q_1,\ldots,q_{a(c)})\in R$ for every constructor $c$ and all
$q_1,\ldots,q_{a(c)}\in R$. For a nullary constructor this requires its
designated state to lie in $R$.
\end{definition}

\begin{theorem}[Finite-cover soundness]\label{thm:finite-cover}
If $R$ is an inductive cover and $R\subseteq G$, then every finite tree
summarises into $G$.
\end{theorem}
\begin{proof}
Induct on a finite constructor tree. The induction hypotheses place every child
summary in $R$; the closure check for its constructor places the parent summary
in $R$ --- for nullary constructors this is exactly the initial-state check.
Conclude with $R\subseteq G$.
\end{proof}

The positive certificate is therefore \emph{a list of state identifiers} and
nothing else. The checker verifies membership, distinctness, all constructor
closures, and $R\subseteq G$. It does not recompute the least reachable set and
does not care how $R$ was found: a larger closed cover is exactly as sound as
the least one, provided it stays inside $G$. That is the cheapest checker in
this document, and it is the reason this lane is the right first end-to-end
Lean milestone even though the polynomial-multiplier lane is mathematically
more substantial.

The proposer saturates, keeping a witness node for every newly reached state
whose children point at previously constructed nodes:

\begin{lstlisting}
reachable := empty state-to-witness map
repeat:
    for each constructor c:
        for each tuple of already reachable child states:
            q := delta_c(tuple)
            if q is new:
                record q with a node pointing to child witnesses
                if q not in good:
                    return concrete_tree_DAG(q)
    if no new state was added:
        return inductive_cover(keys(reachable))
    if resource budget is exhausted:
        return unknown
\end{lstlisting}

The negative certificate is that witness: a list of constructor nodes in which
every child index is strictly smaller than its parent's, plus a designated root.
The checker re-evaluates each node in the \emph{input} algebra and checks the
root state is outside $G$. No search tag substitutes for the tree, and a
malformed self-reference is rejected even when its claimed summary state happens
to be bad.

\begin{theorem}[Completeness for the supplied finite algebra]
Without a resource cutoff, saturation returns either an inductive cover inside
$G$ or a finite tree whose summary is outside $G$.
\end{theorem}
\begin{proof}
At most $|Q|$ states can appear, and every stored state is realised by its
recorded tree; conversely induction on height shows every finite tree's summary
eventually enters the closure. The fixed point is therefore exactly the set of
realisable summaries.
\end{proof}

That completeness is for the \emph{supplied} finite algebra. It is not a claim
that arbitrary recursive functions admit a sufficiently precise finite
abstraction, nor that finite-model reasoning decides Lean inductive goals.

Two fixtures show the range. Counting leaves against internal nodes modulo $m$
uses $Q=(\Z/m\Z)^2$, leaf summary $(1,0)$, node transition
$(\ell_1,n_1),(\ell_2,n_2)\mapsto(\ell_1+\ell_2,n_1+n_2+1)$, and
$G=\{(\ell,n):\ell-n\equiv1\}$; closure is the one-line calculation
$(\ell_1+\ell_2)-(n_1+n_2+1)=(\ell_1-n_1)+(\ell_2-n_2)-1\equiv1$. At $m=12$ the
explicit product has $144$ states and $144^2=20\,736$ binary transition entries,
while the search reaches $12$ states and evaluates $145$ distinct
constructor/child tuples ($235$ including revisits). Those are three different
quantities: building and validating the whole table still costs work
proportional to $20\,736$, so $145$ is not an end-to-end complexity claim. And
the certificate establishes the \emph{congruence}. It does not license
upgrading that congruence to the integer equality $L=N+1$ merely because the
integer equality is what motivated the choice of states.

The second fixture compares a fold with a mirror fold over an arbitrary finite
magma $(A,\star)$, with no associativity assumed: summary
$(u,v)=(\operatorname{fold}(t),\operatorname{fold}(\operatorname{mirror}(t)))$,
leaf $a\mapsto(a,a)$, node
$(u_1,v_1),(u_2,v_2)\mapsto(u_1\star u_2,\ v_2\star v_1)$, good states the
diagonal. If $\star$ commutes the diagonal is closed and associativity is
irrelevant; if some $a\star b\ne b\star a$, the two-leaf tree is already the
counterexample.

\subsubsection*{A finite table is not a model of a Lean definition}

For a source datatype $D$ and summary $\alpha:D\to Q$, each constructor needs a
proved compatibility theorem
\[
 \alpha\bigl(c_D(t_1,\ldots,t_a)\bigr)=
 \delta_c\bigl(\alpha(t_1),\ldots,\alpha(t_a)\bigr),
\]
and the target must follow from $\alpha(t)\in G$. The asymmetry between the two
directions is sharp and easy to get backwards. A positive cover may safely
over-approximate the possible labels and transitions. A \emph{bad abstract
state} does not then give a concrete source counterexample at all --- its
labels or transitions might be unrealisable --- so negative export requires
reconstructing actual source constructors and values and re-checking the
resulting tree. Begin with non-indexed datatypes and registered summary
homomorphisms; mutual recursion, dependent indices, quotient representations,
coinductive streams and general well-founded recursion each need additional
semantics and must not be flattened silently into this signature.

As a worker this needs no automata library: a worklist, a state table, and the
small cover checker suffice, with budgets in state discoveries, tuple
evaluations, table size and certificate size. State-product blow-up is the real
structural limit, and the prototype's transition-evaluation cutoff is a research
safeguard, not hardening against hostile table sizes.

\subsection{What a counterexample here actually refutes}

The closure workers return concrete negative results, and those are worth more
than the usual \unknown{}: a distinguishing word for the linear case, a
concrete orbit point or execution for the polynomial case. Each is validated
independently --- the word is replayed in the \emph{original} matrices, not in
the closure representation.

But the scope statement matters as much as the object.

\begin{remark}[Scope of a distinguishing word]
A replayed word refutes \eqref{eq:linear-goal} \emph{as modelled}. It refutes
the source obligation only to the extent that the modelling is faithful: that
the matrices really are the source updates, that the alphabet really is the
input type, and --- the one most easily forgotten --- that the source admits
\emph{all} words. If the source restricts its inputs and the model did not,
a distinguishing word may be unreachable in the source, and the correct report
is that the model was wrong, not that the program is.
\end{remark}

This places closure counterexamples in the \emph{countermodel replayed} row of
the status lattice (\S\ref{sec:lattice}): they refute the modelled statement for
this system, subject to the recorded assumptions --- which is a strong and
useful result, and is not the same as refuting the Lean goal.

Two further scope conditions are worth naming because they are easy to lose.
Dropping a guard to obtain an unguarded overapproximation is sound in
\emph{one direction only}: a positive invariant of the larger system remains
valid for the guarded one, but a counterexample to the overapproximation need
not be executable in the original. And a rational trace becomes a source-level
counterexample only once its values are well typed and its operations are proved
to match the source --- negative rational states do not refute a
natural-number program.

\begin{remark}[Do not share a ``refuted'' label]
\label{rem:two-lanes}
This section and \S\ref{sec:negative} both produce negative results, and they
mean different things. A replayed execution refutes a \emph{particular
universally quantified machine property}. A Kripke countermodel
(Theorem~\ref{thm:kripke}) classifies a \emph{restricted proof language}: it
says a sequent has no derivation in a named object calculus, while the
corresponding Lean formula may be perfectly provable classically.

An interface that reports both under one generic \textsc{refuted} label would
erase the most important semantic distinction in this design. Concretely, the
Kripke lane's result type must read
\begin{lstlisting}
checkCountermodel G goal cert = true ->
  Not (Nonempty (IPC.Derivation G goal))
\end{lstlisting}
and never \code{Not (denote goal)}. The two lanes are diagnostics of different
kinds and should be reported as such.
\end{remark}

\subsection{What these workers do not do}

The fragment is total, unguarded, polynomial, and finitely controlled. It
contains no integer division, no truncated natural subtraction, no
floating-point rounding, no finite-field interpretation, no variable-length
state, and no uninterpreted operation. Numerical guards, probabilistic choice
and unbounded heap structure are not represented.

Equality of selected observations is not program equivalence. A positive
polynomial identity supplies no termination argument. Leastness of a closure is
a statement about a \emph{vector space}, not a claim to have found the smallest
inductive invariant as a set of states, nor a basis for the ideal of all
polynomial equalities that happen to hold on the reachable set. And vanishing on
a zero set is not the same as membership in the ideal defining it --- radical
and real-algebraic consequences need separate reasoning, which is exactly why
\S\ref{sec:ideal-closure} declines to pass to the radical.

Finally, Noetherian termination is a termination argument. It gives no degree
bound, no runtime bound, and no promise that any particular configured cap is
large enough: a valid problem whose closure exceeds the per-node capacity still
returns \unknown{}, correctly.
