\begin{abstract}
Forge already proposes a proof-planning layer above Lean's \grind{}, including
induction generalization, arithmetic witnesses, nonlinear certificates, and
careful evidence management. This report develops three additional algorithmic
capabilities rather than restating that architecture. First, a descending
sequence of finite-dimensional polynomial spaces discovers jointly inductive
ideals with polynomial transition multipliers. Second, reachable-space closure
proves equivalence of rational weighted representations, or returns a concrete
distinguishing word. Third, a bounded creative-telescoping search synthesizes
recurrences together with regularized, pole-safe summation certificates.
Each worker has an explicit source fragment, a finite acceptance language, a
soundness argument, a sharply delimited completeness statement, and an
implementation path into Lean. The executed corpus contains 27 invariant
certificates, 23 weighted closure certificates, 25 distinguishing words, and
three telescopers; four bounded searches return unknown. Independent replay
works with Python's site packages disabled. The report separates these results
from the still-unimplemented Lean front ends, formalized checker theorems, and
end-to-end tactic benchmarks.
\end{abstract}
