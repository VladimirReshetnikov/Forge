\begin{abstract}
Forge's inspected design already has substantial machinery for induction,
witness synthesis, algebraic and analytic certificates, finite-dimensional
closures, and pushdown summaries. Repeating that architecture would add little.
This article instead specifies two semantic workers and their exact composition.
The first computes backward-closed unsafe regions of finite-control counter
systems using minimal antichains, deciding coverability without bounding the
counters and admitting whole nonnegative affine families of initial states.
The second decides equivalence of deterministic equality-register transducers
over an unbounded alphabet by exploring joint equality orbits, not concrete
keys. Their product handles systems with both a bounded set of remembered names
and an unbounded vector of resource counts.

Each worker has a finite positive receipt, an executable negative witness, a
separate checker, explicit source-translation requirements, and a precise
boundary beyond which it must return unknown or unsupported. Constructive
proofs explain the predecessor formula, parameter separation, fresh-input
coverage, finite-alphabet cutoff, and mixed-model transport. A two-key
exhaustive cache test is shown to miss a three-key, five-request counterexample.
The delivered experiments also include parameterized mutual exclusion,
nonconvex unbounded safety, and an ownership protocol with arbitrarily many
waiting clients. The algorithms have classical foundations; the proposed
contribution is their concrete, narrowly typed integration into Forge, together
with reproducible implementation evidence rather than an assertion of a new
model-checking theory.
\end{abstract}
