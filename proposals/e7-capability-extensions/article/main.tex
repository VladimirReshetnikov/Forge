\begin{abstract}
Forge already has a substantial design for orchestration, proof acceptance,
arithmetic witnesses, induction planning, and certificate-producing backends.
The useful next step is not another orchestration layer. It is a set of workers
that construct proof structure which the existing workers do not yet construct.

This article develops three such extensions. Continuation-local synthesis derives
fold algebras from residual specifications and searches their holes separately,
with an explicit treatment of correlations. Inductive algebra combines a fast
pullback-stable vector-space algorithm with target-seeded ideal completion,
which can discover mutually supporting polynomial equations and generate exact
orbit counterexamples. Cyclic proof compilation treats a recursive obligation
graph as a candidate for ordinary well-founded induction, using synthesized
phase-sensitive or lexicographic rankings rather than accepting a circular proof.

The archive contains runnable Python implementations, an independent exact
replayer, 135 replayed encoded certificates, 31 rejected corruptions, and detailed
experimental records. The results establish the specified finite-fragment
algorithms, not an end-to-end Lean tactic. Lean bridge code and proof specimens
are explicitly separated from executed work.
\end{abstract}
