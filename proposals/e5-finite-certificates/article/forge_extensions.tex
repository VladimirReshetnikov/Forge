\begin{abstract}
The present Forge design already contains a substantial proof-planning layer,
induction and lemma discovery, polynomial recurrence synthesis, arithmetic
witness construction, and several exact certificate families. Recommending
another scheduler or another generic invariant template would not advance it.
This article develops three narrower but substantially stronger mechanisms.
First, observable-space closure decides a finite-dimensional rational
linear-behavior fragment and returns either small matrix certificates or an
explicit distinguishing input word. Second, target-generated pullback ideals
construct mutually supporting polynomial invariants from the goal itself,
avoiding the bilinear search caused by simultaneously guessing invariants and
multipliers. An ascending-ideal argument establishes termination and completeness
for the stated unguarded polynomial fragment, while practical budgets remain
explicit. Third, a pole-free binomial-sum worker synthesizes recurrence and
syzygy certificates by exact linear algebra, preserving endpoints that rational
Gosper certificates can obscure. We give soundness proofs, failure examples,
Lean and Leant integration contracts, concrete library choices, a staged
implementation plan, and reproducible experiments. The recorded run has 38
certificate successes, 17 replayed counterexamples, and four bounded unknowns;
818 single-entry mutations are rejected. None of these counts is a Lean tactic
success rate. The central proposal is to add mathematical closure mechanisms
whose output explains an entire infinite family of executions using finitely
many identities.
\end{abstract}
