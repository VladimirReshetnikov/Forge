\subsection{Running the supplied code}
From the extracted archive:
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
cd prototype
python -S -m unittest discover -s tests -v
python -S verify.py
python -S verify.py ../results/jet-discovery.json
python -S run_experiments.py --out reproduced-results
python -S discover_jets.py --out reproduced-jets.json

# Optional, outside proof acceptance:
python -m pip install mpmath
python numerical_crosscheck.py --out numerical-crosscheck.json
\end{lstlisting}
\end{minipage}\par
The reference environment used Python 3.13.5. The code uses ordinary modern Python features and exact \code{fractions.Fraction}; other versions should be tested rather than assumed bit-for-bit identical. No third-party package is required for search or replay.

To build the article with a reasonably complete TeX Live or MiKTeX installation:
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
cd article
pdflatex -interaction=nonstopmode -halt-on-error forge-extensions.tex
pdflatex -interaction=nonstopmode -halt-on-error forge-extensions.tex
pdflatex -interaction=nonstopmode -halt-on-error forge-extensions.tex
\end{lstlisting}
\end{minipage}\par
The font packages are standard TeX packages; there is no shell escape, bibliography tool, or font-file download step in the build.

\subsection{Reproduction and interpretation notes}
The entry points named \code{prove} are untrusted proposers. Their status tags are meaningful only with the externally supplied problem and the appropriate checker; they do not construct a Lean proof object. Unknown outcomes are stored for audit and are intentionally rejected by certificate replay.

The diagnostic Lean-style expression emitted for the corner witness is a presentation artifact. Its existence is not evidence that a Lean elaborator accepted it. The same applies to the hand-written files in \code{lean/}. Their headers state their uncompiled status, and they introduce no substitute \code{sorry}-based acceptance path.

The preserved results contain the final successful execution of the deterministic suite and the independent replay logs. During preparation, additional mutation cases and the automatic jet profile were added as separate validation increments. There was no failed full-suite run whose result was converted into a successful claim. Future reproductions should preserve failures alongside their command line and environment rather than overwrite them with a later success.
