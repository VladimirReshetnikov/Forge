published paper PDFs, or font files are included. The archive does not modify
or replace the user's repository.

\subsection{Run the experiments}

The code uses Python 3.10 or newer syntax; the recorded execution used 3.13.5.
It requires no installed packages. From the archive root:
\begin{lstlisting}
cd prototype
python -S -m unittest discover -s tests -v
python -S run_experiments.py --output ../reproduced-results/full
python -S replay.py ../results/full/corpus.json
python -S examples.py --output ../reproduced-results/examples
\end{lstlisting}

The experiment harness refuses to overwrite an existing report in its chosen
output directory. Use a new path for each run. If an experiment fails, its
partial corpus, a failure status, and a traceback are retained. The recorded
smoke run is a separate workload and must not be pooled with the full run.

Search-free replay proves only that this Python checker accepted these records
without importing the search or oracle modules. It does not establish that
an arbitrary untrusted execution environment would enforce the import hook,
or that the parser is secure against hostile resource exhaustion.

\subsection{Build the PDF}

The article uses stock pdfLaTeX packages, Latin Modern, and TikZ. No system font
installation, shell escape, bibliography program, or network access is needed.
From \code{article/}, run \code{bash build.sh}, or run the following command
three times:
\begin{lstlisting}
pdflatex -interaction=nonstopmode -halt-on-error \
  forge-alternation-probability.tex
\end{lstlisting}
A PowerShell equivalent is included as \code{build.ps1}. The main source includes
all sections and its bibliography; no external repository checkout is required.

Rationals use canonical integer pairs \code{[numerator, denominator]} with a
positive denominator. JSON floats, duplicate keys, nonfinite values, Boolean
values used as integers, and unreduced fractions are rejected. State sets are
sorted distinct index lists. All matrix dimensions are checked against the
external problem representation. These are reproducibility conventions, not
proofs that the implementation has no parser bugs.

\subsection{The included Lean specimens}

\code{RankTelescoping.lean} gives a natural-number prefix-sum telescoping lemma:
if $r(n+1)+w(n)\le r(n)$, then
$r(n)+\sum_{k<n}w(k)\le r(0)$. It isolates the arithmetic used after a parity
play has entered a fixed threshold tail. It does not formalize the arena,
infinite recurrence, or the threshold checker.

\code{CouplingAlgebra.lean} states a rational finite coupling structure and
proves the direct marginal consequences used in a future finite-sum bridge.
It does not implement the Boolean transport checker, Hall duality, or a
\code{PMF} interpretation. Both files are supplied with proof scripts but were
\textbf{not compiled}. No axiom inventory is reported; the included
\texttt{\#print axioms} commands are instructions for a subsequent actual Lean
execution, not recorded output.
