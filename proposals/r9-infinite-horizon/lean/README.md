# Lean status: no implemented checker in this delivery

No Lean executable was available, and no Lean source was compiled for this work.
This directory deliberately contains no placeholder theorem files presented as
implemented proofs. The article, especially Sections 5–6 and 8, specifies the exact
model semantics, checker soundness statements, source-bridge requirements and
acceptance milestones for a real port.

The first suggested port is the pair of Büchi/co-Büchi rank checkers, followed by
one source-level recurrent strategy theorem. The existing Forge project's core
Lean elaborations are upstream evidence, not evidence for this package.
