\begin{minipage}{0.93\textwidth}
\textbf{The proposed increment.} Replace a search for individually conserved
expressions with an exact, goal-directed closure of polynomial observations.
This proves properties of all finite input sequences and discovers the
relational invariants needed to compare accumulator programs. Add finite Kripke
countermodels as semantic certificates for a precisely delimited constructive
proof-search diagnostic.

\textbf{Executed evidence.} The accompanying package contains 151 passing
Python tests, 37 accepted closure certificates, 28 concrete execution
counterexamples, and 8 accepted Kripke countermodels. All 73 certificates replay
with Python site packages disabled. Nine bounded cases carry no conclusion.

\textbf{Boundary.} This is not an installed Lean tactic. No included Lean source
was compiled here; 222 generated local identity obligations and three generic
induction bridges are supplied as integration targets. There is no measured
comparison against \code{grind} or any other Lean tactic.

\begin{abstract}
Forge already proposes a certificate-producing controller above Lean's local
reasoning engines. Repeating that architecture would not advance the project.
This article instead supplies two operational additions. The first computes the
least family of polynomial vector spaces containing the demanded observations
and closed under coefficientwise pullback along control-flow edges. It emits
finite matrix identities that prove unbounded, arbitrary-input executions by
induction. For updates affine in state, though polynomial in fresh inputs, the
procedure is a decision method in exact arithmetic: a space of dimension at
most $|Q|\binom{r+D}{D}$ suffices for degree-$D$ goals. A failed initial
obligation has a constructive execution witness, not merely a failed invariant
candidate. The second addition proposes and independently checks finite Kripke
countermodels. It establishes nonderivability in a named intuitionistic object
logic, never the negation of an arbitrary Lean proposition. We give complete
mathematical arguments, algorithms, certificate schemas, source-to-Lean
integration plans, implementation constraints, and reproducible synthetic
experiments. The conceptual ingredients are established mathematics; the
contribution is their concrete, incremental application to Forge with a tested
search/checker separation.
\end{abstract}
